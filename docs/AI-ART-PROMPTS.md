# Original AI illustration assets

Created October 7–8, 2026 with the built-in OpenAI image generation tool. Twenty-one distinct illustrations: sixteen event covers and five festival banners. Event names are preserved, and each sample event has its own image. The same event keeps its image across its card, details and schedule so it remains recognizable. Different events never share a cover.

These are imaginative illustrations, not photographs of DRMC or real events. The winter scenes are stylized seasonal artwork, not a factual depiction of Dhaka weather.

Web assets: `public/images/clubos/`, 480px and 960px WebP variants. Original PNG masters and this prompt set are in the separate local `outputs/ClubOS-AI-art.zip`; original PNGs are excluded from the source archive to keep it compact. Newly created events have a typographic cover until dedicated artwork is added, rather than borrowing another event’s illustration.
